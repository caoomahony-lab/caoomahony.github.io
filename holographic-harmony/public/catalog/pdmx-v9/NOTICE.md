# PDMX reference pilot attribution

Derived from **PDMX: A Large-Scale Public Domain MusicXML Dataset for Symbolic Music Processing**, v9.

Creators: Phillip Long, Zachary Novack, Julian McAuley and Taylor Berg-Kirkpatrick.

Pinned source and citation: https://doi.org/10.5281/zenodo.15571083

Source repository and paper references: https://github.com/pnlong/PDMX

Dataset metadata license: **Creative Commons Attribution 4.0 International**.
License: https://creativecommons.org/licenses/by/4.0/

Individual source score labels, original archive paths and source hashes are retained in the manifest. This subset uses public-domain-labelled records with no recorded license conflict, valid associated files, deduplicated source arrangements and successful local analysis. Those are dataset labels rather than an independent determination of each underlying composition's rights.

Changes: selected 500 bounded polyphonic score records; computed Harmonic Savant `score-comparison-v1` descriptors; projected distribution indexes; derived instrument labels from MusicXML; packaged checksum-identified descriptor shards. Raw MusicXML/MXL, MIDI, PDF, lyrics and audio are not redistributed in this pilot.

This is an experimental score/arrangement comparison index. It is not a complete PDMX mirror, an audio catalog, a verified recording database, or a full Harmonic Fingerprint V1/HIR implementation.
