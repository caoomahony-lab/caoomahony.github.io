# HHF-3.8.1 — Mobile hierarchy cleanup

This UI-only checkpoint reduces the long mobile control stack without changing harmonic inference, fingerprint math, continuation generation, or ranking rules.

## Fingerprint explorer

- The current analyzed piece is shown as a compact six-axis report.
- Nearest saved pieces are the default comparison surface.
- Custom fingerprint sliders are hidden behind progressive disclosure.
- The destructive corpus-clear action is moved into a small library menu.
- The current piece is excluded from ordinary nearest-neighbor results.

## Continuation lab

- The continuation lab is collapsed by default under **Continue this harmony**.
- The chord progression remains the primary input.
- Context, system, translation, voicing, ranking, missing-evidence policy, and active/shadow-field controls are grouped under **Advanced options**.
- Existing continuation-engine behavior is unchanged.
